# 夜市治理工作台

面向街道工作人员和现场巡查员的夜市摊位管理单页应用，涵盖摊位证照审核、位置抽签分配、居民投诉处理、现场巡查数据录入和整改跟踪。

## 原始需求

> 做一个街道工作人员和现场巡查员使用的夜市治理页面，Vue3 可以把摊位列表、投诉详情、巡查录入和整改对比分成几个清楚的工作区，页面中的业务数据保存在浏览器本地。页面围绕摊位证照、摊主身份、经营品类、燃气瓶、油烟检测、经营时段、投诉录音和整改照片展开。街道工作人员在页面上审核摊位报名、抽签分配位置、查看居民投诉；巡查员在现场更新油烟数值、占道情况、噪声记录和整改结果。页面要让人一眼看出哪些摊位证照齐全、哪些正在整改、哪些被重复投诉、哪些存在燃气瓶风险。整体风格贴近街道办日常工作台，列表密度可以高一些，但投诉详情、整改照片和油烟趋势不能挤在一起看不清。

## 技术栈

- Vue 3 + TypeScript + Vite
- Tailwind CSS
- Pinia + pinia-plugin-persistedstate（localStorage 持久化）
- Chart.js + vue-chartjs（油烟趋势折线图）
- lucide-vue-next（图标）

## 启动方式

### 前置要求

- Node.js >= 18
- Docker（可选，用于容器化部署）

### Docker 一键启动（推荐）

```bash
docker compose up --build
```

访问地址：http://localhost:8080

后台运行：

```bash
docker compose up --build -d
```

停止服务：

```bash
docker compose down
```

### 本地开发启动

#### 1. 安装依赖

```bash
npm install
```

#### 2. 启动服务

```bash
npm run dev
```

访问地址：http://localhost:5173

#### 3. 构建生产版本

```bash
npm run build
npm run preview
```

## 功能说明

- **摊位列表**：高密度表格展示所有摊位，证照/燃气/整改/投诉状态标签一目了然，支持筛选和搜索
- **摊位抽签**：多维度资格筛选（经营品类、证照状态、违规次数、燃气检查、敏感区域），随机公平抽签，智能位置分配避免高油烟摊位集中，可视化分布图，调整记录留痕，申诉入口
- **投诉详情**：投诉列表按重复次数排序，重复投诉高亮，右侧抽屉展示投诉详情和录音
- **巡查录入**：巡查员录入油烟数值、噪声分贝、占道情况，滑块+数值输入
- **整改对比**：整改前后照片对比，整改状态流转，油烟趋势折线图

## 角色说明

| 角色 | 权限 |
|------|------|
| 街道工作人员 | 审核摊位报名、抽签分配位置、处理投诉 |
| 现场巡查员 | 录入油烟/噪声/占道数据、更新整改状态 |
