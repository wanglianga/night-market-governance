## 1. 产品概述

夜市治理工作台——面向街道工作人员和现场巡查员的夜市摊位管理单页应用。解决夜市摊位证照审核、位置分配、居民投诉处理、现场巡查数据录入和整改跟踪等日常工作痛点，让证照齐全、正在整改、重复投诉、燃气瓶风险等关键状态一目了然。

- 目标用户：街道办工作人员（审核/分配/投诉处理）、现场巡查员（油烟/占道/噪声/整改录入）
- 核心价值：将分散的证照、投诉、巡查、整改信息统一到一个高密度工作台，降低信息遗漏和协同成本

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 街道工作人员 | 选择角色进入 | 审核摊位报名、抽签分配位置、查看/处理居民投诉 |
| 现场巡查员 | 选择角色进入 | 更新油烟数值、占道情况、噪声记录、整改结果 |

### 2.2 功能模块

1. **摊位列表工作区**：摊位证照状态、摊主身份、经营品类、经营时段、燃气瓶风险标记、位置信息
2. **投诉详情工作区**：投诉列表、投诉录音播放、重复投诉高亮、投诉处理状态
3. **巡查录入工作区**：油烟数值录入、占道情况记录、噪声分贝记录、现场照片上传
4. **整改对比工作区**：整改前后照片对比、整改状态跟踪、油烟趋势图表

| 页面名称 | 模块名称 | 功能描述 |

| 夜市治理工作台 | 摊位审核 | 街道工作人员审核摊位报名，查看证照材料 |

## 3. 核心流程

**摊位审核与分配流程**：摊主提交报名 → 街道工作人员审核证照 → 审核通过 → 抽签分配位置 → 摊位正式运营

**巡查与整改流程**：巡查员现场录入数据 → 发现违规 → 生成整改工单 → 摊主整改 → 巡查员录入整改结果 → 整改对比确认

**投诉处理流程**：居民投诉录入 → 街道工作人员查看投诉详情 → 关联摊位 → 处理投诉 → 回访确认

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1e293b）作为工作台底色，体现政务严肃感；警示橙（#f97316）用于风险/待整改；通过绿（#22c55e）用于证照齐全/整改完成
- **辅助色**：浅灰表格底色（#f8fafc）、红色用于燃气瓶风险（#ef4444）、黄色用于重复投诉（#eab308）
- **按钮风格**：小圆角（4px）、紧凑尺寸，工作台风格
- **字体**：思源黑体/Noto Sans SC，正文14px，表头13px加粗，状态标签12px
- **布局风格**：顶部角色切换+统计概览，下方四栏 Tab 切换工作区，工作区内左右分栏（列表+详情）
- **图标**：lucide-vue-next 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 夜市治理工作台 | 顶部统计栏 | 四色统计卡片（证照齐全/待审核/整改中/燃气风险），紧凑布局 |
| 夜市治理工作台 | 摊位列表 | 高密度表格，状态标签列（证照/燃气/整改/投诉），行内操作按钮 |
| 夜市治理工作台 | 投诉详情 | 右侧抽屉面板，录音播放器，投诉时间线，重复投诉标记 |
| 夜市治理工作台 | 巡查录入 | 表单卡片，数值输入+滑块，照片上传区，快捷操作按钮 |
| 夜市治理工作台 | 整改对比 | 并排照片对比区，整改状态时间线，油烟趋势折线图（Chart.js） |

### 4.3 响应式

- 桌面优先设计，最小适配 1280px 宽度
- 表格区域支持横向滚动
- 详情面板使用侧边抽屉，不挤压主列表
- 照片/图表区域保持足够显示空间
